## 🧠 About the Project

**CineMind Pro** is a production-grade, AI-powered movie recommendation system that delivers **personalized movie suggestions** using **Neural Collaborative Filtering**.

The system learns user–movie interaction patterns using **Deep Learning embeddings** and enhances the experience with **real-time movie posters, metadata, and explanations**.

This project demonstrates **end-to-end ML deployment**, from data processing and model inference to UI design and cloud deployment.

---

## ✨ Key Features

- 🎯 Personalized recommendations using Deep Learning  
- 🧠 Neural Collaborative Filtering (User & Movie Embeddings)  
- 🖼️ TMDB API integration for posters & metadata  
- 🎬 Genre & Year filtering (1900–2026)  
- 💡 Explainable recommendations (“Because you liked X”)  
- ⚡ Cached API calls for fast performance  
- 🎨 Modern Netflix-style UI  
- ☁️ Deployed on Streamlit Cloud
